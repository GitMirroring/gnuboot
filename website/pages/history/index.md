Introduction
============

While GNU Boot started around 2023, it has a very long history because
it started from the latest fully free Libreboot release.

* The history of the GNU Boot source code is complex because it
  originally incorporated source code from various other projects
  (Genuine Libreboot, Libreboot, etc) who sometimes have complicated
  histories. The GNU Boot source code history is documented as best we
  could in the [source-code and authorship
  page](source-code-and-authorship.html) however it still contains
  gaps.

* The Libreboot project also maintained [a page](authors.html) that
  credit various Libreboot contributors. We also inherited this page.

* The Libreboot project [old main page](libreboot-index.md) was also
  preserved.
