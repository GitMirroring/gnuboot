Introduction
============

The files referenced below were official GNU Boot news. Most of them
are announcements of the GNU Boot releases. The can be used as
inspiration to announce new releases.

They were added to the GNU Boot as they can be reused (and modified)
to make announce new events.

- [2023-09.mbox](2023-09-23/2023-09.mbox) : Mail in the Mbox format,
